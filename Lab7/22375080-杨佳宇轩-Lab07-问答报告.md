## Question 1

- 区别
  - 字节流: 按字节 ( 8位 ) 处理数据, 适合处理二进制文件 ( 如图片, 音频, 视频等 ); 字节流不对数据进行编码解码, 直接操作字节; 处理非文本数据或需要精确控制字节的内容
  - 字符流: 按字符 ( 16位 ) 处理数据, 适合处理文本文件; 字符流会根据编码规则堆字节进行编码和解码, 转化为字符; 处理纯文本数据使用
- 应该使用 `FileInputStream` 流: 因为可以按字节读取文件内容, 非常适合对文件内容进行逐字节操作
